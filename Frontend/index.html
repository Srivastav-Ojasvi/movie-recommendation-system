How It Works

A content-based filtering pipeline that evaluates similarity through vector representations.

01

Choose a movie

Enter a movie you like into the search system to use as the query reference.

02

Analyze its genres

CineMatch converts movie genre information into high-dimensional numerical features using TF-IDF.

03

Find similar movies

A Nearest Neighbors model using cosine distance identifies movies with similar genre profiles.

04

Get recommendations

The top ranking, most mathematically similar movies are displayed on your screen.

BTech Computer Science Project

About CineMatch

CineMatch is an end-to-end content-based movie recommendation system developed for a BTech Computer Science capstone. It combines information retrieval techniques with machine learning algorithms to solve the cold-start and item recommendation problem.
